# LangChain Gemini Chatbot

A compact chatbot demo using LangChain and Google Gemini. This repository provides both a simple terminal-based runner and an interactive Streamlit UI to explore conversational capabilities. The project emphasizes safe, ethical usage and keeps the API key server-side by default.

**Author**: Ankit Anand

**Status**: Prototype / Experiment

**Contents**
- `model-implementation.py`: Terminal interactive example that prompts the model.
- `app_streamlit.py`: Streamlit-based chat UI for interactive exploration.
- `requirements.txt`: Python dependencies.
- `.env`: Local environment variables (not checked into source control).

**Highlights**
- Uses `langchain_google_genai.ChatGoogleGenerativeAI` as the LLM wrapper.
- Demonstrates a PromptTemplate -> LLM -> OutputParser chain.
- Minimal UI for quick experimentation.

## Requirements

- Python 3.10+ (tested with 3.12)
- Google Cloud / Gemini API access (API key)

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Environment

Create a `.env` file at the project root with your API key:

```text
GOOGLE_API_KEY=your_api_key_here
```

Keep the `.env` file private and never commit it to source control.

## Usage

- Terminal example:

```bash
python modelImplementationUsingLangchain/model-implementation.py
```

- Streamlit UI (recommended for interactive chat):

```bash
python -m streamlit run modelImplementationUsingLangchain/app_streamlit.py
```

Open `http://localhost:8501` in your browser to chat.

## Security & Professional Ethics

This project is intended for research and experimentation. As the author, I, Ankit Anand, recommend the following principles when using or extending this code:

- **Privacy First**: Do not send personal, sensitive, or secret data to the model unless you control the endpoint and have explicit consent from data owners.
- **API Key Safety**: Store API keys in environment variables or a secure secrets manager. Never hard-code credentials or commit them to source control.
- **Responsible Outputs**: Treat model outputs as suggestions. Validate and sanitize any information used for decisions that affect people. Do not rely on the model for legal, medical, or safety-critical guidance without human oversight.
- **Bias Awareness**: Models can reflect and amplify biases. Evaluate outputs for fairness, and add post-processing or guardrails when deploying to real users.
- **Rate Limits & Cost**: Monitor API usage and costs. Add rate limiting or quota checks if you integrate this into a shared service.
- **Attribution & Transparency**: Inform end users when content is generated by an AI and provide instructions for reporting harmful or incorrect outputs.

By using this code you agree to follow these guidelines and to exercise professional responsibility when handling data and deploying models.
